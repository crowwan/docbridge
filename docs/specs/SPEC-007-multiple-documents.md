# SPEC-007 여러 문서 동시에 열기와 문서 사이 복사

## 배경과 목표

지금 docbridge 는 문서를 하나만 연다. 새 문서를 열면 앞 문서를 대신한다(SPEC-002 "새 문서를 열면"). 그런데 받은 한글로 하는 일의 상당수는 **두 문서 사이**에서 일어난다:

- "공고문의 신청 자격을 신청서 표에 채워줘"
- "작년 보고서 3장을 올해 보고서에 가져와"
- "두 공문의 회신 기한이 다른지 봐줘"

이 스펙이 끝나면 여러 문서를 브라우저 탭마다 하나씩 띄워 두고, Claude 가 문서를 골라 읽고 고치며, 문단·표를 한 문서에서 다른 문서로 서식째 복사할 수 있다.

## 동작 정의

### 문서 이름(doc)

- `open_document`·`create_document` 는 앞 문서를 대신하지 않고 **새 탭**에 문서를 연다. 결과에 문서 이름 `doc`(`d1`, `d2` … — 서버가 매기고 닫아도 다시 쓰지 않는다)을 더한다.
- 같은 파일을 다시 열면 새 탭을 만들지 않고 그 문서 탭을 앞으로 보내고 같은 `doc` 을 돌려준다(SPEC-002 "같은 파일 다시 열기" 규칙은 그 문서 안에서 그대로).
- 모든 문서 도구(읽기·하이라이트·편집·저장·스타일)에 `doc`(선택)을 더한다. 없으면 **마지막으로 쓴 문서**(마지막으로 열었거나 도구 대상이 된 문서). 문서가 하나면 지금과 똑같다.
- 블록 id 는 문서마다 따로다(`d1` 의 `b3` 과 `d2` 의 `b3` 은 다른 블록). 결과의 블록 id 는 지금처럼 `b3` 이고, 결과 맨 위에 `doc` 을 붙인다.
- 열 수 있는 문서는 8개까지. 넘으면 "열린 문서가 8개입니다. close_document 로 닫아 주세요." 오류.

### 새 도구

| 도구 | 입력 | 결과 |
|---|---|---|
| `list_documents` | 없음 | `{ documents: [{ doc, fileName, path?, pageCount, unsavedEdits, current }] }` — `current` 는 `doc` 을 안 줬을 때 대상 |
| `close_document` | `doc`(선택) | 탭을 닫는다. 저장하지 않은 편집이 있으면 닫지 않고 "저장하지 않은 편집 n개가 있습니다. 저장하거나 discard: true 로 닫아 주세요." (`discard: true` 면 버림) |
| `copy_blocks` | `from`(원본 doc), `ids`(원본 블록, 이어진 범위), `to`(대상 doc), `before`·`after`(대상 블록) | 원본 문단·표를 서식째 대상 문서에 넣는다(원본은 그대로). 대상 문서의 편집 하나(undo 한 번). 결과 `{ inserted: [새 블록 id], changed: [{ id, number?, text }] }`. 가져올 수 없는 개체가 든 문단이 있으면 아무것도 넣지 않고 거부(`move_blocks` 와 같은 이유 문구) |

### 복사 규칙(`copy_blocks`)

- 원본 범위 규칙은 `move_blocks` 와 같다(id 표로 이어진 블록, 같은 문단 블록은 문단째).
- 글자 모양·문단 모양은 원본 것을 대상 문서로 가져온다. 대상에 같은 스타일 이름이 있으면 그 스타일(스타일 모양이던 글자·문단은 대상 스타일 모양, 굵게 등 직접 서식은 원본 그대로), 없으면 원본 스타일을 이름·모양 그대로 대상에 더한다(ADR 004). 같은 이름 스타일이 둘 남지 않는다.
- 자동 번호 문단은 대상 위치의 번호를 따라 다시 매겨진다: 대상에 같은 모양의 번호 목록이 있으면 그 번호를 잇고, 없으면 새 번호 목록(1부터). 개요 문단은 대상 개요 번호를 따른다(ADR 004).
- 표·그림·누름틀이 든 문단은 그대로 복사한다. 옛 규칙의 도형·글상자도 거부 대상이 아니라 그대로 복사한다(한컴 문서의 사각형·그리기 개체 문단 — HWP 로 바꾼 핸들이 거부하면 HWPX 핸들로 가져온다, ADR 004). 각주·미주·머리말·꼬리말·감추기·책갈피·하이퍼링크 등 rhwp 가 가져오지 못하는 개체가 든 문단이 범위에 있으면 개체만 빼고 넣지 않고 블록째 거부한다(문단마다 이유, `move_blocks` 와 같은 목록 — ADR 004).
- 대상 쪽 기준 규칙은 `insert_paragraph` 와 같다(구역 첫 문단 앞 거부).
- 표 칸 하나의 글자만 옮기는 일은 `read_blocks` + `replace_text` 로 한다(이 도구는 블록째).

### 뷰어 탭

- 문서마다 브라우저 탭 하나. 탭 제목은 파일 이름(새 문서는 `path` 의 이름). 같은 서버·포트, 탭마다 WebSocket 연결 하나.
- 뷰어 도구 막대에 `doc` 이름을 작게 보여 준다(Claude 가 "d2 에 넣었습니다" 할 때 어느 탭인지 알게).
- 도구가 대상으로 삼은 문서 탭을 앞으로 보내지는 않는다(브라우저가 막는 경우가 많다). 대신 하이라이트·편집이 생긴 탭은 탭 제목 앞에 `●` 를 붙이고, 그 탭을 보면 지운다.
- 사용자가 탭을 닫으면 그 문서는 열린 문서에서 빠진다(저장하지 않은 편집은 브라우저 확인 창 — SPEC-002 새로고침 규칙과 같음). 다음 도구 결과에 "d2 탭이 닫혀 문서를 닫았습니다" 를 알린다.

### 예외와 경계 상황

- `doc` 이 없는 이름이면 "열린 문서에 d5 가 없습니다. list_documents 로 확인해 주세요."
- `copy_blocks` 에서 `from` = `to` 면 같은 문서 안 복사로 된다(옮기기가 아니라 사본).
- 한 문서 탭을 새로고침하면 그 문서만 SPEC-002 새로고침 규칙대로 돌아간다.

## 수용 기준

- [ ] AC-1 두 파일을 열면 탭 두 개, `doc` 이 `d1`·`d2` 로 나온다. 같은 파일을 다시 열면 같은 `doc` 이다 (자동)
- [ ] AC-2 `doc` 없이 부른 도구는 마지막으로 쓴 문서를 대상으로 한다 (자동)
- [ ] AC-3 문서마다 블록 id·되돌리기·저장하지 않은 편집 수가 따로다 (자동)
- [ ] AC-4 `list_documents`·`close_document`(저장 안 한 편집 거부, `discard`) (자동)
- [ ] AC-5 `copy_blocks` 가 문단·표를 서식째 다른 문서에 넣고, 대상 번호가 다시 매겨지며, `undo` 한 번에 돌아간다. 원본은 그대로다 (자동)
- [ ] AC-6 대상에 같은 스타일이 없으면 원본 스타일 이름·모양 그대로 들어가고, 있으면 대상 스타일이 되며 같은 이름 스타일이 둘 남지 않는다 (자동)
- [ ] AC-7 9번째 문서를 열면 거부한다 (자동)
- [ ] AC-8 사용자가 탭을 닫으면 그 문서가 빠지고 다음 결과에 알린다 (자동 — E2E)
- [ ] AC-9 실제 공고문의 신청 자격을 실제 신청서에 복사해 저장한 파일이 한글에서 열리고 서식이 맞다 (수동 QA)

## 범위 밖

- 한 탭 안에서 문서를 나란히 보기(분할 화면)
- 문서 비교(diff) 화면 — 바뀐 내용 요약 기능과 함께 따로
- 문서 사이 끌어 놓기(SPEC-006 끌기는 한 문서 안)

## 기술 메모

- 서버: `DocumentSession` 하나 = 문서 하나인 지금 구조를 `doc → DocumentSession` 표로 늘린다. 직렬 큐는 문서마다(다른 문서끼리 동시에 처리해도 됨). "마지막으로 쓴 문서" 는 세션 표가 가진다.
- 브리지: 지금은 연결된 뷰어 중 마지막 것이 활성(`src/server/bridge.ts` activeViewer). 연결할 때 뷰어가 `doc` 을 알리고(새 탭 주소에 `&doc=d2`), 요청을 `doc` 별 연결로 보낸다.
- 복사(ADR 004, #62 기술 검증): 원본 탭이 원본을 HWPX 바이트로 내보내 → 서버 → 대상 탭이 그 바이트를 열어 **HWP 로 한 번 바꾼 핸들**(번호·누름틀 문단은 HWPX 그대로 연 핸들이 거부한다, 거부되면 HWPX 핸들로 한 번 더)에서 `importParagraphBlock`. rhwp 는 글자·문단 모양·스타일·번호 정의·그림을 대상 정의와 내용으로 맞춰 다시 매기고, 없으면 대상에 더한다. docbridge 는 번호 정의(대상의 같은 모양 번호 목록·구역 개요 번호로)와 스타일(대상의 같은 이름으로, 쓰이지 않게 된 복제는 지우거나 "이름 사본N")만 보정한다(`src/core/copy-paragraphs.ts`). `exportSelectionHtml` → `pasteHtml` 대안은 번호·표·그림·스타일을 잃어 쓰지 않는다. 큰 문서(383쪽)는 원본 핸들 만들기에 1초대가 든다.
- 메모리: 문서마다 WASM 문서 핸들이 탭에 따로 있다. 8개 상한은 큰 문서(수백 쪽)에서 탭 메모리를 보고 다시 정한다.

## 열린 질문

- ~~문서 사이 복사가 rhwp 공개 API 로 서식째 되는지~~ — 결정: **된다**(ADR 004, #62). `importParagraphBlock` + 번호·스타일 보정. 대상에 없는 스타일은 바탕글 + 직접 서식 대신 원본 스타일을 더하고, `warnings` 대신 블록째 거부로 바꿨다
- 탭 대신 한 탭 안 문서 목록(사이드바)이 나은지 — 결정: 기술 검증 후 (탭이 많아지면 찾기 어렵다)
